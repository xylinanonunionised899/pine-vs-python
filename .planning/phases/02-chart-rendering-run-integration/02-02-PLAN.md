```tsx
  trades={pineExecutionState.trades}

```
The Python ChartPanel does NOT get a trades prop (it uses a different data path).

**Step 2: Add execution status indicator**
Add a status indicator element immediately AFTER the "Run Pine" button in the action-row div. This is a simple inline element — no new component file needed.

Derive the status from `pineExecutionState`:
- `isRunning === true` → spinning indicator: `<span className="pine-status pine-status--running" title="Executing Pine Script...">⟳ Running</span>`
- `errors.length > 0 && !isRunning` → error indicator: `<span className="pine-status pine-status--error" title={errors[0].message}>✕ Error</span>`
- `lastRunAt !== null && errors.length === 0 && !isRunning` → success indicator: `<span className="pine-status pine-status--success" title="Pine Script executed successfully">✓ Done</span>`
- Otherwise (no run yet) → no indicator shown

Use these exact CSS class names. The indicator text is short (5-8 chars) to fit in the toolbar without wrapping.

**Step 3: Add inline styles for status indicator**
Add a `<style>` block OR inline styles for the status indicator classes. Keep it minimal — this is a toolbar status badge, not a complex component. Use inline styles on the span elements directly (simplest approach, no separate CSS file needed):

- `.pine-status`: `fontSize: "0.75rem"`, `fontWeight: 600`, `padding: "0.15rem 0.5rem"`, `borderRadius: "0.25rem"`, `display: "inline-flex"`, `alignItems: "center"`, `gap: "0.25rem"`, `marginLeft: "0.25rem"`
- `--running`: `color: "#f4b942"`, `animation: "spin 1s linear infinite"` (for the ⟳ character), `background: "rgba(244, 185, 66, 0.1)"`
- `--error`: `color: "#ff6b6b"`, `background: "rgba(255, 107, 107, 0.1)"`
- `--success`: `color: "#20c997"`, `background: "rgba(32, 201, 151, 0.1)"`

Since CSS `@keyframes` cannot be defined inline, use a simpler approach for the running state: apply `style={{ animation: "none" }}` and instead rely on the ⟳ Unicode character being visually distinct. OR add a tiny `<style>` tag in the component return for the spin keyframe:
```tsx
<style>{`@keyframes pine-spin { to { transform: rotate(360deg); } }`}</style>
```
Then use `style={{ animation: "pine-spin 1s linear infinite", display: "inline-block" }}` on just the ⟳ character wrapped in a `<span>`.

**Step 4: Remove redundant last-run text**
The existing `pineExecutionState.lastRunAt` paragraph below the Pine chart (lines 88-93) currently shows "Last Pine run: {time} | {N} trade events". Since the status indicator now shows success/error state and trade count is visible as markers on the chart, simplify this to just the timestamp: `Last run: {time}`. Keep it as-is if you prefer — it is not critical. Do NOT remove it entirely.

- Do NOT modify the Python chart section — it does not need trades or status
- Do NOT add new component files — this is a small inline addition
- Do NOT change any other props or state in WorkspacePage
