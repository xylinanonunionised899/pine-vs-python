<objective>
Extend the existing ChartPanel component to support multi-pane rendering for oscillator indicators and trade marker arrows on the candlestick chart.

Purpose: Currently, oscillator indicators (RSI, MACD, Stoch) are silently hidden by the `isPriceLikeSeries()` filter because their value ranges do not match the price scale. Trade events exist in state but are never rendered on the chart. This plan makes both visible using lightweight-charts v5 native features: `paneIndex` for multi-pane and `createSeriesMarkers()` for trade arrows.

Output: A refactored ChartPanel.tsx that renders overlay indicators on the main pane, oscillator indicators in a sub-pane, and trade markers as buy/sell arrows on the candlestick chart.
</objective>

- Sort markers by time ascending (CRITICAL — `createSeriesMarkers` requires sorted array)
